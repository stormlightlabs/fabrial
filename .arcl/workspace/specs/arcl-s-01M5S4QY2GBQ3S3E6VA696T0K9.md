fabrial is a software factory that takes ready tasks through implement, review, adversarial review and revise until a pull request is ready, and a person merges it. It runs on any number of machines tied to one repository. Its CLI is `fab`.

[PLAN.md](../../../PLAN.md) holds the decisions. This spec's roadmap plan holds the open work.
